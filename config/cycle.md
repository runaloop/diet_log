# Режим

- Глобальный режим: похудение

> `похудение` — дефицит периодизируется по дням по нагрузке (STRATEGY.md §7a):
> отдых/Z1 — дефицит 300–500 (из goals.md), Z2 — 0–150, Z3+/силовая — ~0 (±150);
> после дня с >900 ккал в Z3+ следующий день считается минимум средним.
> `поддержание` — целевой вес достигнут (или диет-брейк): все дни цель ~0 (±150).
>
> Недельный цикл «2 недели дефицит / 1 неделя поддержания» выведен из
> употребления 2026-07-04 — диет-брейк теперь = временное переключение режима.

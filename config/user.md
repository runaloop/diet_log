# Данные пользователя

## Текущие параметры

- Базовый расход (Garmin API, 4-нед среднее покоя, 2026-07-03): 2033 ккал
- Поправка базового расхода: −100 ккал (2026-07-11; Garmin, похоже, завышает — нет голода вечером даже в дефицит)
- **Эффективный базовый расход** = сырой + поправка = 1933 ккал (это число идёт в блок `## План` дневника)

> Базовый расход берётся из API Гармина (расход в покое, RMR — без NEAT, тренировки добавляются сверху): `python3 scripts/garmin_sync.py base`. Обновлять на взвешивании/раз в неделю. До 2026-07-03 константа была 1742 (другой источник, занижена) — прошлые дневники не пересчитаны.
> Поправка — ручная калибровка сырого Garmin-числа под ощущения/динамику веса; в дневник (`## План`) пишется уже эффективный базовый (сырой + поправка), скрипты берут его оттуда. Сырое число и поправку держим раздельно, чтобы `garmin_sync.py base` можно было сверять с константой без потери калибровки.

## Предпочтения по умолчанию

- Если пользователь пишет `овсянка` без уточнения, считать это как `Овсянка сырая`.
- Если пользователь пишет `йогурт виола` или просто `виола` без уточнения, считать это как `Йогурт Viola безлактозный 3%`.
- Если пользователь пишет `молоко` без указания жирности, считать это как `Молоко 2.5%`.

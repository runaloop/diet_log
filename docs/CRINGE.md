# CRINGE.md — анти-паттерны дневного плана

> Живой корпус (STRATEGY.md §16): что делает план непригодным как еду, даже
> когда КБЖУ/группы/квоты сходятся. Критик прогоняет каждый план по этому
> списку перед выдачей. Каждое «это кринж» от пользователя → новый пункт или
> пример к старому. Не удалять пункты без явного решения пользователя.

## 1. Ингредиент как блюдо
Компонент приёма подан самостоятельной строкой: полбанки консервы соло,
сырая крупа отдельной позицией.
- Пример (2026-07-02): «Кукуруза консервированная 130г» + «Фасоль белая 110г»
  двумя строками плана; «Чечевица красная сырая 25г» как блюдо.
- Правило: консервы/крупы/гарниры появляются только внутри приёма при
  основном блюде.

## 2. Удвоенная порция
Порция плана = 2× типичной порции пользователя.
- Примеры (2026-07-02): суп 600г («3 тарелки»), скрембл 500г, TEOS 480г,
  «100г сырой гречки = полкило варёной».
- Правило: одно блюдо = одна медианная порция из истории. Никаких «доешь
  контейнер».

## 3. Однотипность
Несколько блюд одного жанра/группы в одном дне.
- Примеры (2026-07-02): три салата на день; три молочных белковых позиции
  подряд (йогурт + скир + белковое молоко).
- Правило: ≤2 блюд группы в день, разные жанры; второй йогурт — уже на грани.

## 4. Вчерашний повтор без нужды
Блюдо из вчерашнего/позавчерашнего дня при живых альтернативах.
- Пример (2026-07-02): паста Барилла в плане при пасте, съеденной вчера.
- Правило: повтор в пределах окна 7 дней — только если группу больше нечем
  закрыть, и это проговаривается («снова паста — злаки закрыть нечем»).

## 5. Игнор готовки и момента
План требует готовки, несовместимой с усталостью/временем; нет быстрой ветки.
- Пример (2026-07-02): план предполагал варку гречки — обед случился в
  ресторане (пад тай), потому что решение было нужно сейчас.
- Правило: у каждого приёма есть no-cook альтернатива; вечером — минимум
  готовки.

## 6. Недоступная еда
Блюдо из истории, которого нет ни дома, ни в частых ресторанах.
- Пример (2026-07-02): тыквенный крем-суп, съеденный один раз в мае.
- Правило: в план — только `avail` ∈ {always, stock, resto:X}; остальное —
  в «докупить».

## 7. Список вместо приёмов
10+ позиций плоским списком без структуры завтрак/обед/ужин.
- Пример (2026-07-02): 11 строк «поклюй тут, поклюй там».
- Правило: план = 2–4 приёма + перекусы, каждый приём — связная композиция.

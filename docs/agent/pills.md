# Таблетки и БАДы

> Процедура для агента, читается по требованию. Ядро правил — `AGENTS.md`.

Каталог препаратов — `config/medications.md` (локальный, в `.gitignore`, из репозитория не выходит): таблица `Препарат | Доза | Приём | Период | Примечание`. Форматы периода описаны в шапке самого файла (`бессрочно`, `2026-04-01..2026-06-30`, `2026-04-01..бессрочно`, `пн,ср,пт`); примечание `через день` — приём через день от даты начала периода (день попадает, если число дней от начала чётное: 0, 2, 4…). Всё это считает `scripts/pills.py build`, руками даты не считать.

Дневной чеклист — `pills.md` в корне (локальный, не коммитится, в дневник `diaries/…` не вставляется), один файл на проект; история — `pills_history.jsonl` в корне (одна JSON-строка на день `{"date", "items": [{"name","dose","slot","taken"}]}`). Оба пишут скрипты.

## Новый день

Делает `python3 scripts/new_day.py`: внутри него `sync` (сохранить уходящий день, пока `pills.md` не перезаписан) → `build` → `sync`. Руками эти три вызова не повторять. На дату ничего не попадает — файл не создаётся; файл того же дня с отметками не перезаписывается (нужен `--force`).

## Формат `pills.md`

```
# Таблетки 2026-06-28

| · | Препарат | Доза | Приём | Принято |
|---|----------|------|-------|---------|
| 🔲 | Витамин D3 | 2000 МЕ | утро | |
| ✅ | Омега-3 | 1000 мг | вечер | 21:00 |
```

`·` — `✅` если `Принято` заполнено, иначе `🔲`; `Приём` — плановое время из каталога (утро/вечер/обед или конкретное время); `Принято` — фактическое время (ЧЧ:ММ) или `✓`, если время не важно. Заголовок `# Таблетки YYYY-MM-DD` и порядок пяти колонок парсит `pills.py` — не менять. Ровнять — `python3 scripts/format_tables.py pills.md`.

## Отметка приёма

«утренние таблетки», «принял омегу», «вечерние», «таблы»: определить затронутые строки (по времени приёма или названию; не уточнил — все строки текущего планового времени), вызвать `date +%H:%M`, проставить время в `Принято` и `·` → `✅`, затем `python3 scripts/pills.py sync`, чтобы отметка сразу попала в историю (`sync` идемпотентен — перезаписывает строку своей даты).

## История

`python3 scripts/pills.py history [дней]` (по умолчанию 30): по дню строка ✅/🔲 и процент соблюдения по каждому препарату (`✓` ≥90%, `⚠` ≥70%, `✗` ниже). История ведётся с 2026-08-03 — до этого чеклист перезаписывался без сохранения.

## Новый или изменённый препарат

Добавлять в `config/medications.md`; если он нужен уже сегодня — `pills.py build --force` (отметки дня перенести руками, если были). Курс закончился — обновить период в каталоге.

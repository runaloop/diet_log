# Рекомендуемый рацион

> Процедура для агента, читается по требованию. Ядро правил — `AGENTS.md`.

Прогноз дневного рациона из частых продуктов, чтобы заранее попадать в окно дефицита дня, а не вскрывать перебор постфактум. Частотность — `data/profile.json` (`python3 scripts/profile.py`, пересобирать редко: по команде `пересобрать профиль` или при заметном изменении рациона; staple = продукт ≥5 дней в дневниках), подбор — `scripts/plan_ration.py`.

`python3 scripts/plan_ration.py diaries/YYYY/MM/DD.md [--load low|mid|high]` — по блоку `## План` берёт остаток бюджета и предлагает добор из staples дискретными порциями: пустой дневник → план на весь день, частично съеденный → добор остатка. Порядок и ограничения добора (группы недели → белок-флор → угли → жир до флора; кап жира жёсткий) — STRATEGY.md §14. Если белок-флор не влезает в бюджет ккал, скрипт это показывает — это норма, белок важнее точного дефицита. Одно блюдо = одна порция, не масштабируется и не дублируется.

## Генерация — только по запросу

Файл `ration.md` в корне проекта (локальный, в `.gitignore`, в дневник не вставляется); первая строка — `# Рекомендуемый рацион YYYY-MM-DD`. Нет файла — рацион не ведётся, это нормальное состояние. Единственный вход — команда `рацион`:

```
python3 scripts/plan_ration.py diaries/YYYY/MM/DD.md --write --force && python3 scripts/format_tables.py ration.md
```

Без `--force` файл пишется, только если его нет или его дата ≠ дате дня (живой файл с галочками не затирается). Новый день и `setup.sh` файл не создают. **Про остатки со вчера не спрашивать** — ручной инвентарь холодильника выведен из употребления.

**Гарантированные продукты — `--pin`/`--exclude`, не руками.** Продукты, названные пользователем («остатки со вчера», «сегодня хочу X», «X кончился / наскучило»), — аргументы скрипта, агент КБЖУ не считает и `ration.md` руками не пишет:
- `--pin "Название"` — гарантированный продукт, порция по умолчанию из каталога; `--pin "Название:граммы"` — на заданный вес (скрипт масштабирует КБЖУ);
- `--exclude "Название"` — никогда не подставлять автодобором.
Флаги повторяемые; имя матчится по каталогу (точное имя/алиас, иначе подстрока); неоднозначность или отсутствие — скрипт сам падает с понятной ошибкой, не гадать. Пины ставятся только по инициативе пользователя — агент их не выспрашивает. Пример:

```
python3 scripts/plan_ration.py diaries/YYYY/MM/DD.md \
  --pin "Паста Барилла:150" --pin "Стейк из форели" --exclude "Стейк тунца" --write --force
```

## Формат файла

Две таблицы, каждая со своей строкой `ИТОГО`: сверху `## Осталось` (предложено, не съедено, `🔲`), ниже `## Съедено` (принято, `✅`). Колонка **`Блюдо`**, не `Продукт`; `·` у строк `ИТОГО` всегда `—`. Свежий план — весь в `## Осталось`, `## Съедено` пустая (заголовок + нулевое ИТОГО).

```
# Рекомендуемый рацион 2026-06-28

## Осталось

| · | Блюдо | К | Б | Ж | У | Съедено |
|---|-------|---|---|---|---|---------|
| 🔲 | Экспонента 250г | 150 | 30 | 0 | 6 | |
| 🔲 | Сывороточный протеин 30г | 120 | 24 | 2 | 2 | |
| — | **ИТОГО** | **270** | **54** | **2** | **8** | |

## Съедено

| · | Блюдо | К | Б | Ж | У | Съедено |
|---|-------|---|---|---|---|---------|
| ✅ | Банан 100г | 89 | 1 | 0 | 23 | 11:20 |
| — | **ИТОГО** | **89** | **1** | **0** | **23** | |
```

Файл справочный: в `**Потреблено:**` и блок `## План` не входит, дневниковые скрипты его не видят. Строки `ИТОГО` и раскладку по таблицам пересчитывает `python3 scripts/sort_ration.py ration.md`; ровнять — `format_tables.py ration.md`. Если пользователь назвал блюда явно и файл правится руками — Б по строкам не считать: `python3 scripts/ration_totals.py ration.md diaries/YYYY/MM/DD.md --write` пересчитывает оба `ИТОГО` и печатает сверку с белком-флором (`✓`/`⚠`); не хватает — добавить белковых блюд и прогнать снова.

## Чек = лог

«Съел боул», «банан из плана»:
1. залогировать блюдо в дневник как обычно — `python3 scripts/log.py "<блюдо>"` (таблица питания остаётся единственным источником `Потреблено`);
2. в строке `ration.md` проставить `Съедено` = то же время, `·` → `✅`;
3. `python3 scripts/sort_ration.py ration.md && python3 scripts/format_tables.py ration.md` — `✅`-строка переезжает в «Съедено», оба `ИТОГО` пересчитываются.

Съел вне плана → только `log.py`, в `ration.md` не вносить. Файла `ration.md` нет — шаги 2–3 пропустить.

## Отклонение от плана

Если `ration.md` существует и пользователь заметно отклонился (переел/недоел) — перегенерировать невычеркнутые строки под новый остаток (`--write --force`, при необходимости с `--pin` уже намеченных блюд), дискретными порциями, не одним блюдом. Файла нет — ничего не создавать.
